# Changelog

All notable changes are recorded here. The project follows a spec-driven workflow; the specs under `specs/` are the long-form record.

## 0.1.0 — 2026-09-05

First public release: overlay chat over a local model, screen reading (window-scoped), verified input control with approval gates and dangerous-verb prompts, memory with redaction, MCP servers and skill packs, the coding agent with its VS Code bridge, native integrations (CLI/TUI, Finder, paste, hotkey), Teach Me mode, the system tools (`open`, `wait_for_text`, `ui_action`, `browser`, `text_selection`, `find_files`, `processes`, `mac`), lane health, always-on logs with copyable run reports, deterministic and live eval harnesses, Homebrew distribution and in-app update checks.
