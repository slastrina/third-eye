# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, be constructive, assume good faith, and keep discussions about the work. Harassment, personal attacks, and discrimination of any kind are not tolerated.

Report problems by opening an issue marked *conduct* or by contacting the maintainer through GitHub. Reports are handled privately and promptly.
