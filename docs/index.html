A local AI that can see your screen and use your Mac.

Third Eye is a summonable overlay that pairs a language model running on your machine with real eyes and hands. It reads what is on screen, drives your apps, runs commands, edits code, and remembers — and every action is checked against what the OS actually did.

Download for macOS Source on GitHub
🔒 Local-first · nothing leaves your Mac by default 🧾 MIT licensed 🦀 Tauri + Rust + React

What it does

One hotkey, one panel, a model that can look and act. Each capability is a tool with a typed contract — the model cannot narrate past a failure.

See

Reads the screen the way you do

The focused window through the accessibility tree first, on-device OCR second — with real click targets, in a few hundred milliseconds.

Act

Uses your apps for real

Clicks, typing and shortcuts; presses controls by name; talks to Chrome's tabs and page; reads and rewrites the text you selected in any app.

Verify

Every action reports back

Where the cursor really landed, which app holds focus, whether the text arrived. A wrong-app readback is a failure the model must handle.

Teach

Teach Me mode

Flip a toggle and it does things the human way — visible keyboard and mouse only, narrated, ending with a numbered "do it yourself" recap.

Code

A coding agent, too

Workspace tools, diffs in the loop, a VS Code extension that shows edits live, and a thirdeye CLI and TUI.

Remember

Memory that stays yours

A local store with categories, tags, pins and expiry. Facts ride the system turn automatically. Transcripts are redacted before they are saved.

Built to be trusted with a keyboard

The design rule is structure over prose: a small local model treats instructions as advisory, so the guarantees live in code, not in the prompt.

  • Three run modes — Off, Ask, Auto-run — with per-kind session grants and a persistent command allowlist.
  • Dangerous verbs always ask. sudo, rm, kill, git push, uploads, pipe-to-shell — allowlisted or not, and "always" never sticks.
  • Grounding. A click needs coordinates from a screen read; a navigation needs a URL you gave or it read. Guesses are refused, typed.
  • Budgets and breakers end loops: opens earned by reading, a search budget, a repeat breaker, a stuck breaker that forces a text answer.
  • Redaction at the choke points and a fail-closed guard that refuses non-local endpoints unless you opt in.
  • Every run leaves a report you can copy into a bug report; the log is always on.

Install

macOS 14+ and LM Studio serving a tool-capable model on localhost:1234. Unsigned builds need a right-click → Open the first time.

Homebrew

brew tap slastrina/tap
brew trust slastrina/tap
brew install --cask third-eye

Or grab the DMG from Releases, drag Third Eye to Applications, open it, and follow the four-step tour (Accessibility, Screen Recording, and what each is for). The app tells you when a newer release exists.

From source

git clone https://github.com/slastrina/third-eye.git
cd third-eye
npm install
make install-app
